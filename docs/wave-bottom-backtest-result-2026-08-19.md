# 重点底部波段信号回测结果（2026-08-19）

## 结论

`pair-wave-bottom-v1` 的技术链路和回测程序验证通过，但当前评分阈值 **未通过策略有效性验收，不建议直接作为正式强信号使用**。

主要原因：

- 1,013 个有效独立样本中，仅 5 个达到 `CANDIDATE`（70～84分），覆盖率仅 0.49%；
- 最高分为 75，`STRONG`（85分以上）为 0 个；
- 5 个候选样本的20日收益中位数较高，但样本过少，95% bootstrap 区间为 0%～34.139%，不能证明稳定优势；
- 候选组20日正收益率为80%，反而低于全部FOCUS基准的98.223%；
- 当前样本处于明显上涨阶段，所有FOCUS底部的20日收益中位数已经达到10.553%，没有市场基准或多年熊市样本，不能把绝对上涨归因于波段评分。

因此，页面可以把它保留为“研究观察”列，但不能把70分或85分信号解释为已经回测验证的交易信号，也不应修改原有 `pair-trend-v3` 阶段。

## 下一步建议

1. 当前公式保持 `pair-wave-bottom-v1` 不变，不根据这一个测试期直接降低阈值。
2. 补充至少3～5年、包含熊市和震荡市的历史FOCUS事件及日K。
3. 增加同日期市场基准和随机股票匹配组，报告市场超额收益，而不只看绝对收益。
4. 将历史分成训练、验证、测试三段，只在训练/验证段调整组件定义和阈值。
5. 重点评估50～60分区间，并验证“突破前10日压力”是否过严，但任何修改都必须升级为新算法版本重新回测。
6. 最终测试期要求至少500个有效样本、STRONG至少80个且跨3个自然年度方向一致；当前结果不满足。
